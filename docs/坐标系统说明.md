# 3D 编辑器坐标系统说明

## 坐标系来源

### 1. **世界坐标轴 (World Axes) - `THREE.AxesHelper`**
来源：`three.js` 核心库

- **红色轴**：X 轴（正方向向右）
- **绿色轴**：Y 轴（正方向向上）
- **蓝色轴**：Z 轴（正方向向前）

这是 Three.js 提供的内置辅助工具，用于显示世界坐标系。

### 2. **视口坐标轴 (Viewport Axes) - `AxisHelper`**
来源：`@3d-editor/engine` 自定义实现

这是我们在 `packages/engine/src/helpers/AxisHelper.ts` 中实现的自定义坐标轴辅助器：

```typescript
export class AxisHelper {
  private worldAxes: THREE.AxesHelper        // 世界坐标系（固定在原点）
  private viewportAxes: THREE.AxesHelper     // 视口坐标系（固定在右上角）
  
  // 每帧更新，让视口坐标系跟随相机旋转
  update(camera: THREE.Camera): void {
    const invQuat = new THREE.Quaternion().copy(camera.quaternion).invert()
    this.viewportAxes.quaternion.copy(invQuat)
  }
}
```

**功能**：
- `worldAxes`：显示在场景原点 (0,0,0)，始终指向世界坐标方向
- `viewportAxes`：固定在视口右上角，跟随相机旋转，帮助用户了解当前视角方向

### 3. **变换控制器 (TransformControls / Gizmo)**
来源：`three/examples/jsm/controls/TransformControls.js`

这是 Three.js 官方示例库中的交互式变换工具，提供：
- **移动 Gizmo**：三色箭头（XYZ）
- **旋转 Gizmo**：三色圆环（XYZ）
- **缩放 Gizmo**：三色立方体（XYZ）

我们在 `packages/engine/src/controls/TransformController.ts` 中封装了它。

## 坐标系在编辑器中的应用

### Editor.vue (通用 3D 编辑器)
- ✅ 世界坐标轴：显示在场景原点
- ✅ 视口坐标轴：右上角显示当前视角方向（通过 `ctx.axisHelper.update(camera)` 每帧更新）
- ✅ 变换 Gizmo：选中对象时显示，用于交互式编辑

### FactoryEditor.vue (智慧工厂编辑器)
- ✅ 世界坐标轴：网格地板提供参考
- ✅ 变换 Gizmo：选中模型后可移动/旋转/缩放
- ⚠️ 视口坐标轴：暂未启用（可按需添加）

## 当前问题与修复

### 问题 1: TransformControls 死循环
**原因**：`TransformController` 构造函数中错误地监听了 `dragging-changed` 并设置 `this.controls.enabled = !value`，导致递归调用。

**修复**：移除 `TransformController` 中的事件监听器，由外部（Editor.vue / FactoryEditor.vue）负责处理。

```typescript
// packages/engine/src/controls/TransformController.ts
constructor(camera: THREE.Camera, dom: HTMLElement) {
  this.controls = new TransformControls(camera, dom)
  this.controls.setMode('translate')
  // ❌ 移除有问题的事件监听器
  // this.controls.addEventListener('dragging-changed', ...)
}
```

### 问题 2: 材质颜色读取错误
**原因**：某些对象（如 GridHelper、AxesHelper）没有 `material` 属性或不是 `MeshStandardMaterial`。

**修复**：在 `selectedObject` computed 中添加安全检查。

```typescript
// 安全获取材质颜色
let materialColor = '#ffffff'
if (obj.material && 'color' in obj.material) {
  const mat = obj.material as THREE.MeshStandardMaterial
  if (mat.color && typeof mat.color.getHexString === 'function') {
    materialColor = '#' + mat.color.getHexString()
  }
}
```

### 问题 3: Quaternion.inverse() 方法不存在
**原因**：Three.js r160+ 版本将 `inverse()` 改为 `invert()`。

**修复**：在 `AxisHelper.update()` 中使用 `invert()` 替代 `inverse()`。

```typescript
// packages/engine/src/helpers/AxisHelper.ts
update(camera: THREE.Camera): void {
  const invQuat = new THREE.Quaternion().copy(camera.quaternion).invert()
  this.viewportAxes.quaternion.copy(invQuat)
}
```

## 如何正确使用坐标系

### 1. 初始化时添加到场景
```typescript
// 在 CoreContext 初始化后
ctx.value.scene.add(ctx.value.transform.controls)
ctx.value.axisHelper.showWorldAxes(true)
ctx.value.axisHelper.showViewportAxes(true)
```

### 2. 每帧更新视口坐标轴
```typescript
// 在渲染循环中（CoreContext 已自动处理）
ctx.axisHelper.update(camera)
```

### 3. 处理 Gizmo 与 OrbitControls 冲突
```typescript
// 在组件中监听事件
ctx.value.transform.controls.addEventListener('dragging-changed', (event: any) => {
  if (ctx.value) {
    // 拖拽时禁用轨道控制器
    ctx.value.orbit.controls.enabled = !event.value
  }
})
```

## 总结

| 组件 | 来源 | 功能 | 是否在 engine 中 |
|------|------|------|-----------------|
| `THREE.AxesHelper` | three.js 核心 | 世界坐标轴 | ✅ 通过 AxisHelper 封装 |
| `AxisHelper` | @3d-editor/engine | 视口坐标轴管理 | ✅ |
| `TransformControls` | three.js examples | 变换 Gizmo | ✅ 通过 TransformController 封装 |
| `OrbitControls` | three.js examples | 轨道相机 | ✅ 通过 OrbitController 封装 |

所有坐标系功能都已集成在 `@3d-editor/engine` 中，业务层只需通过 `CoreContext` 访问即可。
