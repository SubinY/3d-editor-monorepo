# 架构调整说明 - 吸附功能与网格系统

## 📦 包结构调整

### 1. SnapSystem 从 engine 迁移到 extensions

**调整理由**：
根据项目设计原则（`AI架构Prompt.md`），`@3d-editor/engine` 只提供 3D 编辑器的**必需能力**，吸附功能不是所有编辑器都需要的，因此移至 `@3d-editor/extensions`。

**变更内容**：
```
删除: packages/engine/src/helpers/SnapSystem.ts
新增: packages/extensions/src/snap/index.ts
```

**影响**：
- `CoreContext` 不再包含 `snap` 属性
- 需要吸附功能的编辑器需要手动导入 `SnapSystem`

---

## 🎯 编辑器功能差异

### Editor.vue (通用 3D 编辑器)
- ❌ **不使用**吸附功能
- ✅ **使用**无限网格 (`InfiniteGridHelper`)
- ✅ 自由放置和变换对象
- ✅ 适用于通用 3D 场景编辑

**代码示例**：
```typescript
// 无吸附，直接设置位置
obj.position.set(p[0], p[1], p[2])

// 无限网格
const infiniteGrid = new InfiniteGridHelper(1, 100)
ctx.value.scene.add(infiniteGrid)
```

---

### FactoryEditor.vue (智慧工厂编辑器)
- ✅ **使用**吸附功能（从 `@3d-editor/extensions` 导入）
- ✅ **使用**无限网格 (`InfiniteGridHelper`)
- ✅ 网格吸附（gridSize = 2）
- ✅ 地板边界绘制功能（框选定义场景边界）
- ✅ 适用于工业场景布局规划

**代码示例**：
```typescript
import { SnapSystem } from '@3d-editor/extensions'

// 创建吸附系统实例
const snap = ref<SnapSystem>(new SnapSystem({ gridSize: 2 }))

// 使用吸附
const snappedPos = snap.value.snapPosition(position)
group.position.copy(snappedPos)

// 无限网格
const infiniteGrid = new InfiniteGridHelper(2, 100)
ctx.value.scene.add(infiniteGrid)

// 地板边界（可编辑）
function updateFloorBoundary(width: number, depth: number) {
  const boundaryGeo = new THREE.EdgesGeometry(new THREE.PlaneGeometry(width, depth))
  const boundaryMat = new THREE.LineBasicMaterial({ color: '#00aaff' })
  const boundary = new THREE.LineSegments(boundaryGeo, boundaryMat)
  boundary.rotation.x = -Math.PI / 2
  boundary.position.y = 0.01
  ctx.value.scene.add(boundary)
}
```

## 🌐 无限网格系统

两个编辑器都使用 `InfiniteGridHelper`（来自 `three/examples/jsm/helpers/InfiniteGridHelper.js`）：

### 优势
- ✅ 无限延伸，不受固定尺寸限制
- ✅ 自动根据相机距离调整网格密度
- ✅ 视觉效果更好，不会在边缘突兀结束

### 参数说明
```typescript
new InfiniteGridHelper(
  gridSize: number,   // 网格单元大小（Editor: 1, Factory: 2）
  gridDivisions: number  // 细分级别（通常 100）
)
```

## 🏗️ 地板搭建功能（FactoryEditor 专属）

### 功能说明
用户可以通过框选方式定义工厂场景的边界区域：

1. **点击"绘制地板"按钮** 🔲
2. **第一次点击**：记录起点
3. **移动鼠标**：显示预览矩形
4. **第二次点击**：确定终点并创建地板边界

### 当前实现状态
- ✅ 边界显示（蓝色发光边框）
- ✅ 边界更新函数 `updateFloorBoundary(width, depth)`
- 🚧 交互式框选逻辑（TODO）

### 后续完善

## 🔄 迁移指南

### 如果你的代码使用了 SnapSystem

**之前**:
```typescript
import { CoreContext } from '@3d-editor/engine'

const ctx = new CoreContext({ container })
ctx.snap.snapPosition(position) // ❌ 不再可用
```

**现在**:
```typescript
import { CoreContext } from '@3d-editor/engine'
import { SnapSystem } from '@3d-editor/extensions'

const ctx = new CoreContext({ container })
const snap = new SnapSystem({ gridSize: 2 })
snap.snapPosition(position) // ✅ 正确
```
