# @3d-editor/engine 缺失功能分析

## ✅ 已实现的核心功能

当前 `@3d-editor/engine` 已经实现了以下核心能力：

1. **CoreContext** - 场景上下文管理
2. **Renderer** - WebGL 渲染器
3. **RenderLoop** - 渲染循环
4. **CameraManager** - 相机管理
5. **OrbitController** - 轨道控制器
6. **TransformController** - 变换控制器（Gizmo）
7. **SelectionManager** - 对象拾取
8. **HistoryManager** - 历史记录
9. **AnimationSystem** - 动画系统
10. **SceneSerializer** - 场景序列化
11. **GeometryFactory** - 几何体工厂
12. **MaterialFactory** - 材质工厂
13. **LightingFactory** - 灯光工厂

## ❌ 缺失的关键功能

### 1. **事件系统 (EventBus)** ⭐⭐⭐

**问题**:
- 场景中的变化（如 Gizmo 拖拽）无法自动通知 UI 层
- 需要手动通过 `updateTrigger` 强制刷新视图
- 缺少全局事件通信机制

**建议实现**:
```typescript
// packages/engine/src/events/EventBus.ts
export class EventBus {
  on(event: string, callback: Function): void
  off(event: string, callback: Function): void
  emit(event: string, data?: any): void
}

// 事件类型
export enum EditorEvents {
  OBJECT_SELECTED = 'object:selected',
  OBJECT_TRANSFORMED = 'object:transformed',
  OBJECT_ADDED = 'object:added',
  OBJECT_REMOVED = 'object:removed',
  SCENE_UPDATED = 'scene:updated',
  TOOL_CHANGED = 'tool:changed'
}
```

**使用场景**:
```typescript
// 在 TransformController 中
this.controls.addEventListener('change', () => {
  eventBus.emit(EditorEvents.OBJECT_TRANSFORMED, { object })
})

// 在 Vue 组件中
ctx.value.eventBus.on(EditorEvents.OBJECT_TRANSFORMED, () => {
  // 自动更新 UI，无需手动 trigger
})
```

### 2. **坐标系辅助管理器 (AxisHelper)** ⭐⭐

**问题**:
- 缺少专门的坐标系辅助管理
- 需要手动创建 `THREE.AxesHelper` 和配置显示位置
- 没有世界坐标系/局部坐标系切换功能

**建议实现**:
```typescript
// packages/engine/src/helpers/AxisHelper.ts
export class AxisHelper {
  private worldAxes: THREE.AxesHelper
  private viewportAxes: THREE.AxesHelper // 固定在右上角的迷你坐标系
  
  constructor(size: number = 5)
  showWorldAxes(show: boolean): void
  showViewportAxes(show: boolean): void
  updateViewportAxes(camera: THREE.Camera): void // 跟随相机旋转
}
```

### 3. **网格吸附系统 (SnapSystem)** ⭐⭐⭐

**问题**:
- 当前只有简单的手动 `Math.round` 吸附
- 缺少对齐、吸附到其他对象、吸附到网格的完整功能
- 没有吸附可视化反馈

**建议实现**:
```typescript
// packages/engine/src/helpers/SnapSystem.ts
export interface SnapOptions {
  enabled: boolean
  gridSize: number
  snapToGrid: boolean
  snapToObjects: boolean
  snapAngle: number // 角度吸附（如 15°）
}

export class SnapSystem {
  constructor(options: SnapOptions)
  
  snapPosition(position: THREE.Vector3): THREE.Vector3
  snapRotation(rotation: THREE.Euler): THREE.Euler
  snapScale(scale: THREE.Vector3): THREE.Vector3
  
  // 吸附到其他对象的边界
  snapToBounds(object: THREE.Object3D, targets: THREE.Object3D[]): void
}
```

### 4. **场景图管理器 (SceneGraphManager)** ⭐⭐

**问题**:
- 缺少对场景图的高级操作
- 没有成组/解组、父子关系管理
- 缺少层级显隐、锁定功能

**建议实现**:
```typescript
// packages/engine/src/scene/SceneGraphManager.ts
export class SceneGraphManager {
  group(objects: THREE.Object3D[]): THREE.Group
  ungroup(group: THREE.Group): THREE.Object3D[]
  
  setParent(child: THREE.Object3D, parent: THREE.Object3D): void
  setVisible(object: THREE.Object3D, visible: boolean): void
  setLocked(object: THREE.Object3D, locked: boolean): void
  
  // 层级管理
  bringToFront(object: THREE.Object3D): void
  sendToBack(object: THREE.Object3D): void
  moveUp(object: THREE.Object3D): void
  moveDown(object: THREE.Object3D): void
}
```

### 5. **对齐工具 (AlignmentTool)** ⭐⭐

**问题**:
- 缺少对象对齐功能（左对齐、居中、均匀分布等）
- 没有相对于其他对象或场景中心的对齐

**建议实现**:
```typescript
// packages/engine/src/tools/AlignmentTool.ts
export enum AlignType {
  LEFT, CENTER, RIGHT,
  TOP, MIDDLE, BOTTOM,
  DISTRIBUTE_H, DISTRIBUTE_V
}

export class AlignmentTool {
  align(objects: THREE.Object3D[], type: AlignType, reference?: THREE.Object3D): void
  distributeHorizontally(objects: THREE.Object3D[]): void
  distributeVertically(objects: THREE.Object3D[]): void
}
```

### 6. **多选管理 (MultiSelection)** ⭐⭐⭐

**问题**:
- `SelectionManager` 只支持单选
- 无法框选多个对象
- 无法对多个对象同时应用变换

**建议实现**:
```typescript
// 扩展 SelectionManager
export class SelectionManager {
  private selectedObjects: Set<THREE.Object3D> = new Set()
  
  select(object: THREE.Object3D, additive: boolean = false): void
  deselect(object: THREE.Object3D): void
  selectAll(): void
  clearSelection(): void
  
  // 框选
  selectByRect(rect: { x: number, y: number, width: number, height: number }): void
  
  getSelection(): THREE.Object3D[]
  isSelected(object: THREE.Object3D): boolean
}
```

### 7. **撤销/重做完善** ⭐⭐

**问题**:
- 当前 `HistoryManager` 需要手动构建 Command
- 没有自动记录 Transform 变化
- 缺少批量操作的事务支持

**建议实现**:
```typescript
// 扩展 HistoryManager
export class HistoryManager {
  // 自动记录变换
  recordTransform(object: THREE.Object3D, before: Transform, after: Transform): void
  
  // 事务支持
  beginTransaction(name: string): void
  endTransaction(): void
  cancelTransaction(): void
  
  // 自动快照
  enableAutoSnapshot(interval: number): void
}
```

## 📦 包级归属（依据《AI架构Prompt.md》）

根据 Prompt 中“只提供内核能力、界面由业务实现”的原则：

### 📌 核心包 `@3d-editor/engine` 必须补齐

| 能力 | 说明 | 所属理由 |
| --- | --- | --- |
| EventBus | 内部子系统通信、UI 同步 | 属于“内核调度能力” |
| MultiSelection | 场景编辑基础功能 | 与核心交互紧耦合 |
| SnapSystem | 变换控制基础，可直接影响 Gizmo | 与 Transform/Selection 强相关 |
| AxisHelper | 世界坐标/局部坐标参考 | 属于渲染/辅助工具基础 |
| SceneGraphManager | 对象层级、锁定、显隐 | 属于场景管理核心 |
| AlignmentTool（基本对齐+分布） | 与多选、Gizmo 配合 | 保障基础编辑效率 |
| HistoryManager 自动快照 | Undo/Redo 基础能力 | Prompt 中明确属于内核 |

> ✅ 实施方式：在 `packages/engine/src` 下新增 `events/`, `helpers/`, `scene/`, `tools/` 子目录，提供纯逻辑/渲染辅助类，并在 `CoreContext` 中实例化或通过依赖注入暴露。

### 🔌 扩展包 `@3d-editor/extensions` 实现

| 能力 | 说明 | 理由 |
| --- | --- | --- |
| MaterialEditor | 材质参数调优、纹理管理 | 属于“扩展子包”中的业务增强 |
| ModelImporter / SceneExporter | GLTF/FBX/OBJ 导入导出 | 文档中归于扩展能力 |
| PerformanceMonitor | FPS/DrawCall/内存监控 | 可由扩展面板消费 |
| 高级对齐（参考线、吸附到自定义锚点） | 在基础对齐之上 | 方便定制但非内核必需 |
| PostProcessing 管线 | Bloom/Outline 等业务场景化特效 | 可按需启用的扩展 |

> ⚙️ extensions 内可复用 engine 暴露的事件/场景能力，通过插件形式 `(ctx: CoreContext) => void` 注入。
