# 多选和高亮功能说明

## 📋 功能概述

本次更新为编辑器核心包添加了完整的多选和视觉反馈功能：

1. ✅ **多对象选择** - 支持Ctrl+点击多选
2. ✅ **选中对象描边** - 绿色边缘高亮显示
3. ✅ **多对象变换** - 支持同时移动/旋转/缩放多个对象
4. ✅ **UI反馈** - 显示选中对象数量和ID列表

---

## 🎯 核心API变化

### 1. SelectionManager 新增方法

```typescript
// 获取所有选中对象的UUID列表
getSelectionIds(): string[]

// 获取选中对象的数量
getSelectionCount(): number

// 切换对象的选中状态
toggle(object: THREE.Object3D): void
```

**使用示例:**

```typescript
const ctx = new CoreContext({ container })

// 选中对象
ctx.selection.select(mesh1, false) // 单选
ctx.selection.select(mesh2, true)  // 追加选择

// 获取选中的ID列表
const ids = ctx.selection.getSelectionIds()
console.log('选中了', ids.length, '个对象')

// 切换选中状态
ctx.selection.toggle(mesh3) // 如果已选中则取消，否则选中

// 检查是否被选中
if (ctx.selection.isSelected(mesh1)) {
  console.log('mesh1 已被选中')
}
```

---

### 2. SelectionHighlight 选中高亮效果

新增的 `SelectionHighlight` 类提供选中对象的视觉反馈。

```typescript
import { SelectionHighlight } from '@3d-editor/engine'

// 创建高亮效果管理器
const highlight = new SelectionHighlight(scene, {
  color: 0x00ff00,      // 高亮颜色（绿色）
  thickness: 2,         // 线条粗细
  pulsate: true,        // 是否启用脉动效果
  glow: 0              // 发光强度
})

// 为单个对象添加高亮
highlight.add(mesh)

// 为多个对象设置高亮
const selection = ctx.selection.getSelection()
highlight.setHighlightedObjects(selection)

// 更新动画（在渲染循环中调用）
highlight.update(delta)

// 清除所有高亮
highlight.clear()

// 改变高亮颜色
highlight.setColor(0xff0000) // 红色

// 清理资源
highlight.dispose()
```

**特性:**
- ✅ 使用边缘线实现，性能友好
- ✅ 支持脉动动画效果
- ✅ 自动跟随对象变换
- ✅ 不依赖后处理，兼容性好

---

### 3. TransformController 多对象支持

`TransformController` 现在支持同时操作多个对象。

```typescript
// 单对象操作（原有功能）
ctx.transform.attach(mesh)

// 多对象操作（新功能）
const selection = ctx.selection.getSelection()
ctx.transform.attachMultiple(selection)

// 获取当前附加的对象
const attached = ctx.transform.getAttachedObject()

// 检查是否在多选模式
if (ctx.transform.isMultiSelection()) {
  console.log('正在操作多个对象')
}

// 取消附加
ctx.transform.attach(null)
```

**多对象变换原理:**
- 创建临时 `THREE.Group` 包含所有选中对象
- Group中心位于所有对象的质心
- 变换完成后自动解散Group，保持对象在原父级
- 完全保持世界坐标一致性

### 4. CoreContext 集成

`CoreContext` 已自动集成 `SelectionHighlight`：

```typescript
const ctx = new CoreContext({ container })

// 访问高亮管理器
ctx.highlight.setHighlightedObjects(objects)
ctx.highlight.setColor(0xff0000)
ctx.highlight.update(delta)

// CoreContext 会自动：
// 1. 在渲染循环中更新高亮动画
// 2. 在dispose时清理高亮资源
```

## 🖱️ 用户交互

### 编辑器中的多选操作

#### 1. **鼠标点击选择**

```typescript
// 单击 - 单选对象
点击mesh → 选中单个对象 → 自动进入移动模式

// Ctrl+点击 - 多选/取消选择
Ctrl+点击mesh1 → 保持原有选中，添加mesh1
Ctrl+点击mesh2 → 再添加mesh2
Ctrl+点击mesh1 → 取消mesh1的选中
```

#### 2. **场景树选择**

```typescript
// 点击场景树节点
点击节点 → 单选该对象

// Ctrl+点击场景树节点
Ctrl+点击 → 追加/取消选择
```

#### 3. **空白处点击**

```typescript
点击空白处 → 取消所有选择 → 隐藏Gizmo和描边
```

## 📊 UI层数据绑定

### Vue组件中使用

```vue
<script setup>
import { ref } from 'vue'
import { CoreContext } from '@3d-editor/engine'

const ctx = ref<CoreContext>()
const selectedObjectIds = ref<string[]>([])

// 更新选中列表
const updateSelection = () => {
  if (!ctx.value) return
  
  // 获取选中的ID列表
  selectedObjectIds.value = ctx.value.selection.getSelectionIds()
  
  // 更新描边显示
  const selection = ctx.value.selection.getSelection()
  ctx.value.highlight.setHighlightedObjects(selection)
  
  // 更新TransformControls
  if (selection.length === 1) {
    ctx.value.transform.attach(selection[0])
  } else if (selection.length > 1) {
    ctx.value.transform.attachMultiple(selection)
  } else {
    ctx.value.transform.attach(null)
  }
}

// 在模板中显示
</script>

<template>
  <div>
    <p>已选中 {{ selectedObjectIds.length }} 个对象</p>
    
    <!-- 场景树 -->
    <div v-for="obj in sceneObjects" 
         :key="obj.id"
         :class="{ selected: selectedObjectIds.includes(obj.id) }">
      {{ obj.name }}
    </div>
  </div>
</template>
```

## 🔧 高级配置

### 自定义高亮颜色

```typescript
// 初始化时配置
const ctx = new CoreContext({ container })
ctx.highlight.setColor(0xff0000) // 红色

// 或者重新创建
import { SelectionHighlight } from '@3d-editor/engine'

ctx.highlight.dispose()
ctx.highlight = new SelectionHighlight(ctx.scene, {
  color: 0x00ffff,    // 青色
  thickness: 3,       // 更粗的线条
  pulsate: false,     // 禁用脉动
})
```

### 禁用某些对象的选中

```typescript
const handlePointerDown = (event: PointerEvent) => {
  const result = ctx.selection.pick(...)
  
  // 过滤不可选对象
  if (result.object) {
    // 过滤辅助对象
    if (result.object.type === 'GridHelper' ||
        result.object.type === 'AxesHelper') return
    
    // 过滤TransformControls
    if (result.object.type === 'TransformControls' ||
        result.object.parent?.type === 'TransformControlsGizmo') return
    
    // 自定义过滤
    if (result.object.userData.nonSelectable) return
    
    // 选中对象
    ctx.selection.select(result.object)
  }
}
```

## 📝 完整示例

```typescript
import { CoreContext, EditorEvents } from '@3d-editor/engine'
import * as THREE from 'three'

// 初始化
const ctx = new CoreContext({ container })

// 创建一些对象
const mesh1 = new THREE.Mesh(
  new THREE.BoxGeometry(),
  new THREE.MeshStandardMaterial({ color: 0xff0000 })
)
mesh1.position.set(-2, 0, 0)

const mesh2 = new THREE.Mesh(
  new THREE.BoxGeometry(),
  new THREE.MeshStandardMaterial({ color: 0x00ff00 })
)
mesh2.position.set(2, 0, 0)

ctx.scene.add(mesh1, mesh2)

// 点击处理
canvas.addEventListener('pointerdown', (event) => {
  const result = ctx.selection.pick(
    event.clientX,
    event.clientY,
    ctx.renderer.domElement,
    ctx.scene.children
  )
  
  if (result.object && result.object instanceof THREE.Mesh) {
    if (event.ctrlKey) {
      // Ctrl多选
      ctx.selection.toggle(result.object)
    } else {
      // 单选
      ctx.selection.select(result.object)
    }
    
    // 更新视觉反馈
    const selection = ctx.selection.getSelection()
    ctx.highlight.setHighlightedObjects(selection)
    
    // 更新TransformControls
    if (selection.length === 1) {
      ctx.transform.attach(selection[0])
    } else if (selection.length > 1) {
      ctx.transform.attachMultiple(selection)
    }
    
    // 打印选中信息
    console.log('已选中:', ctx.selection.getSelectionIds())
  } else {
    // 取消选择
    ctx.selection.clear()
    ctx.highlight.clear()
    ctx.transform.attach(null)
  }
})

// 监听选中事件
ctx.eventBus.on(EditorEvents.OBJECT_SELECTED, (data) => {
  console.log('对象被选中:', data)
})
```

## ⚠️ 注意事项

### 1. 多对象变换的限制

- 多对象同时变换时，它们被临时放入一个Group中
- Group的中心是所有对象的质心
- 变换完成后对象会回到原父级，保持世界坐标

### 2. 性能考虑

- 描边使用 `EdgesGeometry`，对复杂模型可能影响性能
- 建议选中对象不超过50个
- 可以通过 `highlight.clear()` 临时禁用描边

### 3. 事件处理

- 使用 `event.ctrlKey` 或 `event.metaKey` 检测多选
- Mac上使用 Cmd键（metaKey），Windows/Linux使用Ctrl键
- 确保过滤掉不可选对象（辅助对象、Gizmo等）

## 🔄 从单选迁移到多选

### 旧代码（单选）

```typescript
const selectedObject = ref<THREE.Object3D | null>(null)

const handleClick = () => {
  selectedObject.value = mesh
  ctx.transform.attach(mesh)
}
```

### 新代码（支持多选）

```typescript
const selectedObjects = ref<THREE.Object3D[]>([])
const selectedIds = ref<string[]>([])

const handleClick = (event: PointerEvent) => {
  if (event.ctrlKey) {
    ctx.selection.toggle(mesh)
  } else {
    ctx.selection.select(mesh)
  }
  
  selectedObjects.value = ctx.selection.getSelection()
  selectedIds.value = ctx.selection.getSelectionIds()
  
  ctx.highlight.setHighlightedObjects(selectedObjects.value)
  ctx.transform.attachMultiple(selectedObjects.value)
}
```
