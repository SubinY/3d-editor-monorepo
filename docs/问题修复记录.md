# 问题修复记录

## 浏览器报错修复

### 1. ❌ `Maximum call stack size exceeded` - TransformControls 死循环

**报错信息**:
```
TransformControls.updateMatrixWorld (three_examples_jsm_c…s?v=d3268b81:137:19)
```

**原因分析**:
在 `TransformController` 构造函数中错误地监听了 `dragging-changed` 事件并设置 `this.controls.enabled = !value`，导致：
1. `dragging-changed` 触发
2. 设置 `enabled` 属性
3. 触发 Three.js 内部的矩阵更新
4. 再次触发 `dragging-changed`
5. 无限递归 ❌

**修复方案**:
```typescript
// packages/engine/src/controls/TransformController.ts
export class TransformController {
  constructor(camera: THREE.Camera, dom: HTMLElement) {
    this.controls = new TransformControls(camera, dom)
    this.controls.setMode('translate')
    // ✅ 移除有问题的事件监听器，由外部处理
    // ❌ this.controls.addEventListener('dragging-changed', ...)
  }
}
```

**外部正确处理方式**:
```typescript
// Editor.vue / FactoryEditor.vue
draggingHandler = (event: { value: boolean }) => {
  if (ctx.value) {
    // ✅ 在外部控制 OrbitControls 的启用/禁用
    ctx.value.orbit.controls.enabled = !event.value
  }
}
ctx.value.transform.controls.addEventListener('dragging-changed', draggingHandler)
```

### 2. ❌ `Cannot read properties of undefined (reading 'color')` - 材质颜色读取错误

**报错信息**:
```
at ComputedRefImpl.fn (Editor.vue:351:59)
```

**原因分析**:
场景中的某些对象（如 `GridHelper`、`AxesHelper`、`TransformControls`）：
- 没有 `material` 属性
- 或者 `material` 不是 `MeshStandardMaterial`
- 导致读取 `obj.material.color` 时出错

**修复方案**:
```typescript
// apps/demo-vue3/src/views/Editor.vue
const selectedObject = computed(() => {
  updateTrigger.value
  
  if (!selectedObjectId.value || !ctx.value) return null
  const obj = ctx.value.scene.getObjectByProperty('uuid', selectedObjectId.value) as THREE.Mesh
  if (!obj) return null
  
  // ✅ 安全获取材质颜色
  let materialColor = '#ffffff'
  if (obj.material && 'color' in obj.material) {
    const mat = obj.material as THREE.MeshStandardMaterial
    if (mat.color && typeof mat.color.getHexString === 'function') {
      materialColor = '#' + mat.color.getHexString()
    }
  }
  
  return {
    transform: { /* ... */ },
    material: { color: materialColor }
  }
})
```

同样修复 `updateMaterial()`:
```typescript
const updateMaterial = () => {
  if (!selectedObjectId.value || !ctx.value || !selectedObject.value) return
  const obj = ctx.value.scene.getObjectByProperty('uuid', selectedObjectId.value) as THREE.Mesh
  if (!obj || !obj.material) return
  
  // ✅ 安全更新材质颜色
  if ('color' in obj.material) {
    const mat = obj.material as THREE.MeshStandardMaterial
    if (mat.color && typeof mat.color.set === 'function') {
      mat.color.set(selectedObject.value.material.color)
    }
  }
}
```

### 3. ❌ `Uncaught TypeError: camera.quaternion.clone(...).inverse is not a function`

**报错信息**:
```
at AxisHelper.update (AxisHelper.ts:53:50)
```

**原因分析**:
Three.js r160+ 版本 API 变更：
- `Quaternion.inverse()` → ❌ 已移除
- `Quaternion.invert()` → ✅ 新方法

**修复方案**:
```typescript
// packages/engine/src/helpers/AxisHelper.ts
update(camera: THREE.Camera): void {
  if (!this.viewportAxes.visible) return
  
  // ✅ 使用 invert() 替代 inverse()
  const invQuat = new THREE.Quaternion().copy(camera.quaternion).invert()
  this.viewportAxes.quaternion.copy(invQuat)
}
```

### 5. 🐛 长按移动等操作无法使用

**问题描述**:
拖拽 Gizmo 进行移动/旋转/缩放时，操作卡顿或失效。

**原因分析**:
1. TransformControls 与 OrbitControls 冲突
2. 事件监听器配置错误导致控制失效

**修复方案**:
```typescript
// 正确配置拖拽冲突处理
ctx.value.transform.controls.addEventListener('dragging-changed', (event: any) => {
  if (ctx.value) {
    // 拖拽时禁用轨道控制器
    ctx.value.orbit.controls.enabled = !event.value
  }
})

// 正确监听对象变换
ctx.value.transform.controls.addEventListener('objectChange', () => {
  const object = ctx.value?.transform.controls.object
  if (!object || !ctx.value) return
  
  // 应用吸附
  object.position.copy(ctx.value.snap.snapPosition(object.position))
  
  // 触发 UI 更新
  updateTrigger.value++
  
  // 发射事件
  ctx.value.eventBus.emit(EditorEvents.OBJECT_TRANSFORMED, { id: object.uuid })
})
```

function startLoop() {

## 新增功能

### 7. ✨ 支持键盘删除对象

**功能说明**:
按下 `Delete` 或 `Backspace` 键删除选中的对象。

**实现**:
```typescript
const deleteSelection = () => {
  if (!ctx.value || !selectedObjectId.value) return
  const obj = ctx.value.scene.getObjectByProperty('uuid', selectedObjectId.value)
  if (!obj) return
  
  // 不允许删除辅助对象
  if (obj.type === 'GridHelper' || obj.type === 'AxesHelper' || obj.type === 'TransformControls') return
  
  ctx.value.scene.remove(obj)
  ctx.value.eventBus.emit(EditorEvents.OBJECT_REMOVED, { id: selectedObjectId.value })
  selectObject(null)
}

// 监听键盘事件
window.addEventListener('keydown', (event) => {
  if (event.key === 'Delete' || event.key === 'Backspace') {
    deleteSelection()
  }
})
```

## 坐标系说明

### 8. 📐 坐标系来源与功能

所有坐标系功能均来自 `@3d-editor/engine`：

| 组件 | 来源 | 功能 |
|------|------|------|
| `THREE.AxesHelper` | three.js 核心 | 世界坐标轴（固定在原点） |
| `AxisHelper` | @3d-editor/engine | 视口坐标轴管理（固定在右上角） |
| `TransformControls` | three.js examples | 变换 Gizmo（移动/旋转/缩放） |

**使用方式**:
```typescript
// 显示世界坐标轴
ctx.value.axisHelper.showWorldAxes(true)

// 显示视口坐标轴（右上角）
ctx.value.axisHelper.showViewportAxes(true)

// CoreContext 会在每帧自动更新视口坐标轴
// ctx.axisHelper.update(camera) 已在 RenderLoop 中调用
```

详见 `docs/坐标系统说明.md`。
