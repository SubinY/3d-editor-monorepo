# 恢复到标准网格

## 变更说明

根据用户反馈，移除了无限网格功能，恢复到 Three.js 标准的 `GridHelper`。

## 已还原的内容

### 1. Editor.vue (通用编辑器)
- ❌ 移除 `InfiniteGridHelper` 导入
- ✅ 恢复使用 `THREE.GridHelper(50, 50)`
- ✅ 保持无吸附功能

### 2. FactoryEditor.vue (智慧工厂编辑器)
- ❌ 移除 `InfiniteGridHelper` 导入
- ❌ 移除地板边界绘制功能（`isDrawingFloor`、`floorBoundary`、`toggleFloorDrawing`）
- ❌ 移除"绘制地板"按钮
- ✅ 恢复原始地板实现（固定尺寸 80x40）
- ✅ 保留吸附功能（gridSize=2）

### 3. engine 包
- ❌ 删除 `InfiniteGrid.ts` 文件
- ❌ 从 `index.ts` 移除导出

## 当前状态

### Editor.vue
```typescript
// 使用标准网格
const grid = new THREE.GridHelper(50, 50, 0x888888, 0x444444)
ctx.value.scene.add(grid)
```

### FactoryEditor.vue
```typescript
// 固定地板 + 网格 + 边框
const w = 80, h = 40
const floor = new THREE.Mesh(floorGeo, floorMat)
const grid = new THREE.GridHelper(w, w / 2, '#4466aa', '#1a2b4d')
const border = new THREE.LineSegments(borderGeo, borderMat)
```
