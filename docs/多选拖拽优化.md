# 多选拖拽优化：解决 TransformControls 消失问题

## 问题描述

用户报告：多选物体后，执行移动、旋转等操作一次，三维坐标（TransformControls）就会消失。

## 根本原因分析

### 问题1：重复attach导致多选组被解散

`TransformController.attachMultiple()` 的执行流程：
1. 调用 `detachInternal()` 解散之前的多选组
2. 创建新的临时 Group
3. 将对象移入 Group
4. attach Group 到 TransformControls

如果在拖拽过程中或拖拽结束后，有任何逻辑重新调用 `attachMultiple()`（即使是相同的对象集合），都会导致：
- 多选组被解散
- 对象被移回原父级
- 重新创建多选组
- TransformControls可能在这个过程中失去附加的对象

### 问题2：拖拽结束后的click事件误触发

拖拽 TransformControls 结束时（mouseup），浏览器可能会紧接着触发 `click` 事件。这个 click 事件会被 `handlePointerDown` 捕获，导致：
- 如果拾取到物体，会触发单选逻辑（清除之前的多选）
- 如果没有拾取到物体，会清空所有选择

虽然有 `if (ctx.value.transform.controls.dragging) return` 检查，但 `dragging` 属性在 mouseup 时已经变为 `false`，所以这个检查无效。

## 解决方案

### 修复1：避免重复attach相同的对象集合

在 `TransformController.attachMultiple()` 开头添加检查：

```typescript
// 检查是否已经附加了相同的对象集合，避免重复创建
if (this.multiSelectionGroup && this.multiSelectionGroup.children.length === objects.length) {
  const currentChildren = new Set(this.multiSelectionGroup.children)
  const allSame = objects.every(obj => currentChildren.has(obj))
  if (allSame) {
    // 已经附加了相同的对象，不需要重新创建
    return
  }
}
```

**效果**：如果多选组已经存在并包含相同的对象，直接返回，不进行任何操作。这避免了不必要的解散和重建。

### 修复2：防止拖拽结束后的click事件

在 `Editor.vue` 中：

1. 添加状态标志：
```typescript
let justFinishedDragging = false
```

2. 在 `dragging-changed` 事件处理器中设置标志：
```typescript
draggingHandler = event => {
  if (ctx.value) {
    ctx.value.orbit.controls.enabled = !event.value
    
    // 拖拽结束时设置标志，防止紧接着的click事件误触发选择
    if (!event.value) {
      justFinishedDragging = true
      setTimeout(() => {
        justFinishedDragging = false
      }, 100)
    }
  }
}
```

3. 在 `handlePointerDown` 中检查标志：
```typescript
const handlePointerDown = (event: MouseEvent) => {
  if (!ctx.value) return
  
  // 如果正在拖拽 TransformControls，不处理点击
  if (ctx.value.transform.controls.dragging) return
  
  // 如果刚完成拖拽，不处理点击（防止拖拽结束后的click事件）
  if (justFinishedDragging) return
  
  // ... 后续逻辑
}
```

**效果**：拖拽结束后的100ms内，忽略所有click事件，防止误触发选择逻辑。

## 设计原则

### 1. 幂等性原则
- `attachMultiple(同一组对象)` 应该是幂等的
- 多次调用不应导致副作用
- 避免不必要的解散和重建

### 2. 状态保护原则
- 拖拽操作是用户的主要交互
- 拖拽过程中和结束后应保护选择状态
- 使用时间窗口防止误触发

### 3. 事件隔离原则
- 拖拽事件和点击事件应该隔离
- 不同交互模式不应相互干扰
- 使用标志位管理状态转换
