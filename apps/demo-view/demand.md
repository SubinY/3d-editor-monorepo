电控柜3D资源编辑器 MVP版本需求文档
文档版本：1.0
编制日期：2026年2月
适用范围：MVP版本（资产文件管理 + 资产编辑器主体 + 场景编辑器主体）
1. 引言
1.1 目的
本文档定义电控柜3D资源编辑器的MVP版本功能需求，用于指导开发实现，支持用户快速构建和管理电控柜3D资产及现场场景。
1.2 项目背景
针对电控柜运维中非标设备多、建模成本高的问题，提供资产组合与场景排布能力，实现高效复用和可视化管理。
2. 总体描述
2.1 项目目标

实现从CAD模型到完整电柜资产的快速构建。
支持资产在场景中的灵活排布与管理。
提供统一的资产文件管理体系，确保资产可重复使用和版本可控。
形成MVP闭环：资产创建 → 资产管理 → 场景构建。

2.2 用户角色

管理员/建模工程师：负责资产创建、维护和场景搭建。
运维人员：使用已构建的资产和场景进行查看。

2.3 范围
纳入范围：

资产文件管理
资产编辑器主体功能（电柜资产构建）
场景编辑器主体功能（现场排布）

排除范围：

PLC数据绑定、实时通信、诊断高亮
AR/VR扩展
权限系统、云同步（MVP阶段）

3. 功能需求
3.1 资产文件管理

资产库的浏览、搜索与分类管理
新资产的上传与导入
资产版本的创建、查看、回滚与对比
资产的预览、删除、移动与批量操作
资产包的导出与下载

3.2 资产编辑器

CAD模型的导入与处理
组件库的调用与管理
组件的自由组合与装配
资产层次结构的创建与调整
资产参数的编辑
装配过程的实时预览与校验
资产的保存与版本更新

3.3 场景编辑器

资产实例的加载与管理
场景中资产的布局与空间排列
资产的批量操作与分组管理
场景辅助工具的使用
场景视图的导航与切换
完整场景的保存与导出

4. 非功能需求

性能：支持单资产编辑流畅，支持场景中至少20个柜体实例实时操作。
可用性：界面简洁直观，支持中文操作，符合工业软件使用习惯。
兼容性：支持主流浏览器环境，资产文件格式通用。
可扩展性：模块化设计，便于后续增加新功能。
可靠性：资产保存与导出过程数据完整无丢失。
安全性：本地文件操作安全，防止误删重要资产。

5. 假设与依赖

用户具备基本3D建模知识。
输入CAD文件格式符合行业标准。
运行环境满足基本图形计算能力。

6. 附录

验收标准：MVP版本可完整完成“导入CAD → 构建电柜资产 → 管理资产 → 搭建场景 → 导出场景”的全流程。
后续迭代方向：预览、实时数据集成、诊断功能、权限控制等。
