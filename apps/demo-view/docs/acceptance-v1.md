# 电柜设备运维 3D 编辑器 v1 验收清单

- 文档版本：v1.0
- 编制日期：2026-02-26
- 对应需求文档：`apps/demo-view/docs/demand-v1.md`
- 验收范围：仅 `资产 -> 场景`，不含 `scene -> scene`

## 1. 验收前准备

- [ ] 本地可启动 `apps/demo-view`，并能进入 `asset-library`、`asset-editor`、`scene-editor` 页面。
- [ ] 浏览器支持 IndexedDB，且可正常读写。
- [ ] 准备导入样本：
  - `apps/demo-view/src/assets/mounted_motor_electrical_component/scene.gltf`
  - `apps/demo-view/src/assets/mounted_motor_electrical_component/scene.bin`
  - `apps/demo-view/src/assets/mounted_motor_electrical_component/textures/*`

## 2. P0 功能验收

### 2.1 导入与存储（GLB 源资产）

- [ ] 支持导入 `.glb` 文件并完成预览。
- [ ] 导入 `.gltf` 目录输入时，系统可完成入库（内部统一转存/归档为 GLB）。
- [ ] 导入完成后，资产库可见缩略图、名称、尺寸、三角面统计。
- [ ] 二进制模型数据写入 IndexedDB（而非写入超大 JSON 到 localStorage）。
- [ ] 资产记录包含 `storageVersion` 与 `sourceResourceId`（或同等字段）。
- [ ] 刷新页面后，已导入资产仍可正常加载。

### 2.2 资产编辑碰撞校验（仅提示）

- [ ] 拖拽组件时可进行节流碰撞检测（AABB）。
- [ ] 变换结束后可生成碰撞结果列表。
- [ ] 保存资产前会执行碰撞检测并提示结果。
- [ ] 有碰撞时不阻止保存（仅提示）。
- [ ] 冲突对象可高亮并支持“一键定位/聚焦”。

### 2.3 钻取只读（资产编辑器 + 场景编辑器）

- [ ] 可按配置开关控制模型/Mesh 是否允许钻取。
- [ ] 触发钻取后相机可平滑聚焦到目标包围盒。
- [ ] 钻取态支持面包屑返回与 `Esc` 退出。
- [ ] 钻取态下禁用变换编辑（只读查看）。
- [ ] 退出钻取态后恢复正常编辑能力。

### 2.4 资产到场景链路

- [ ] 在资产编辑器完成拼装并保存后，资产库可见新资产。
- [ ] 在场景编辑器可从资产侧栏/库中拖拽资产实例到场景。
- [ ] 场景保存后刷新可恢复资产实例布局。
- [ ] 场景中的资产钻取仅影响查看，不改写资产源数据。

## 3. 非目标回归检查（必须满足）

- [ ] 不存在“场景拼装场景（scene -> scene）”入口或行为。
- [ ] 不存在“导出资产包/场景包/BOM”入口或行为。
- [ ] 不存在“碰撞失败阻止保存”或“自动修正位姿”行为。
- [ ] 不存在复杂装配结构能力（锚点/插槽/自动布置）。

## 4. 性能与稳定性验收

- [ ] 5-20MB 级别模型可在可接受时间内完成预览（参考目标：3 秒量级）。
- [ ] 10-20 个资产实例场景可流畅编辑（无持续性严重掉帧）。
- [ ] IndexedDB 中资源缺失时可给出可理解错误，不白屏。
- [ ] 可兼容读取 v0.x 资产/场景记录。
