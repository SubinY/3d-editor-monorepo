MVP版本功能大纲（完整、可独立运行的资产编辑器 + 场景编辑器 + 资产文件管理）
1. 资产文件管理（全局基础模块）

资产库浏览与搜索（按类型、名称、日期过滤）
新资产上传/导入（支持批量）
资产版本管理（查看历史版本、回滚、对比）
资产预览与快速查看（缩略图 + 3D旋转预览）
资产删除、移动、分类标签管理
导出资产包（单个或批量）

典型交互：

左侧固定侧边栏为“资产库”面板，顶部搜索框 + 分类标签 + 网格/列表切换；
点击资产缩略图 → 弹出预览窗口或直接进入资产编辑器；
拖拽资产缩略图到场景编辑器视口即可实例化；
右键资产 → 菜单（版本历史、导出、删除）。

2. 资产编辑器（电柜资产构建主体）

CAD模型导入与自动转换（支持STEP/IGES等常见格式）
组件库调用（预置元器件、柜体基础件，可搜索/分类）
自由拖拽组合装配（组件放置到柜体上）
层次结构管理（树形查看/重命名/分组/解组/层级调整）
参数化编辑（位置、旋转、缩放、简单尺寸调整）
实时碰撞检测与自动吸附辅助
3D预览与校验（完整性检查、爆炸视图切换）
保存为新资产或覆盖当前版本

典型交互：

主视口实时3D操作（旋转、缩放、平移）；
左侧组件库面板 → 拖拽组件到视口自动吸附/放置；
右侧属性面板显示选中节点属性 + 层次树（拖拽调整层级）；
顶部工具栏（导入CAD、爆炸/还原、撤销/重做、对齐工具）；
底部状态栏显示当前装配状态与校验结果；
右键节点弹出快捷菜单（删除、编组、隐藏）；
“保存资产”按钮 → 弹出名称/版本/描述确认框，成功后返回资产库。

3. 场景编辑器（现场排布主体）

加载已有资产作为实例（支持多选批量加载）
场景布局与变换（自由摆放柜体、调整位置/旋转/间距）
批量操作（多选、复制、阵列排列、对齐、均匀分布）
分组与层级管理（按区域/起重机分组、显示/隐藏层）
辅助工具（地面网格、测量工具、坐标轴参考）
视图导航（自由相机、正交六视图、焦点锁定）
预览与导出完整场景（glTF + 场景配置文件）

典型交互：

主视口显示完整3D场景（多柜并存）；
左侧资产库面板 → 拖拽资产缩略图到视口即创建实例；
右侧场景树面板（可折叠分组、拖拽调整顺序）+ 属性面板（批量修改变换值）；
顶部工具栏（多选模式、阵列工具、测量、视图切换、地面开关）；
Gizmo变换控件（移动/旋转/缩放手柄）；
右键空白处或实例弹出菜单（粘贴、群组、删除）；
“导出场景”按钮 → 选择保存路径，生成可直接用于Web展示的资产包。

MVP交付标准

三个模块无缝切换（资产库 ↔ 资产编辑器 ↔ 场景编辑器）；
全程支持撤销/重做、保存/加载；
资产与场景文件格式统一（glTF为主 + 轻量JSON配置）；
基础性能满足10-20个柜体实时编辑（后续可优化）；
纯离线可用（文件本地读写）。

此MVP已覆盖“从CAD到完整可用场景”的核心闭环，后续迭代可在此基础上扩展。需要我进一步细化某个模块的交互流程图描述或优先级调整，请随时说。
