# 电柜设备运维 3D MVP 开发需求

## 1. 结论

结合现有代码，当前仓库的 `engine + presets + extensions` 定位为：

- **固定场景的 3D 面板编辑运行时内核**（渲染、交互、编辑动作、预设、插件能力）。
- **不承担业务型资产文件管理系统**（资产分类、版本、检索、批处理、权限等应在应用层实现）。

因此本项目可支持电柜运维 3D MVP，边界为：

- **内核负责**：3D 场景编辑能力与可复用编辑基础设施。
- **demo-view 应用负责**：资产文件管理、业务流程编排、页面与数据持久化。

## 2. 现有可复用能力

### 2.1 内核已具备能力

- `CoreContext`：运行时主干（场景、相机、渲染循环、选中、变换、插件与事件总线）
- `EditorActions`：编辑动作层（增删对象、分组拆组、对齐，已与历史机制绑定）
- `SceneSerializer`：场景序列化/反序列化
- `SnapPlugin`：网格与角度吸附插件
- `factoryPreset`：工厂地板预设（反射地板、边框、尺寸标注、灯光、相机）

### 2.2 现有页面可复用能力

- `apps/demo-vue3/src/views/factory/FactoryEditor.vue`：设备拖拽实例化、选中、高亮、变换
- `apps/demo-vue3/src/views/Editor.vue`：场景树、属性面板、多选、分组

## 3. MVP 四大基础能力

> 目标：支撑电柜设备运维的基础软件闭环——**创建、维护、场景搭建、查看**。

| 能力 | 说明 |
|------|------|
| **创建** | 资产编辑器中编排电柜（元器件 3D 组合），保存到资产库 |
| **维护** | 资产库中对已有资产编辑、重命名、版本管理 |
| **场景搭建** | 场景编辑器中拖拽资产实例排布，保存/加载场景 |
| **查看** | 只读模式打开场景或资产，供运维人员浏览 |

## 4. MVP 版本规划

按版本拆分，每版独立交付、可单独验收。

| 版本 | 主题 | 状态 |
|------|------|------|
| v0.1 | 资产编辑器单页 | ✅ 已完成 |
| v0.2 | 资产库（分类 Tab）+ 场景编辑器（工厂地板 + 配置面板） | ✅ 已完成 |
| v0.3 | 场景 ↔ 资产编辑器打通 + 资产编辑器加载已有资产 | ✅ 已完成 |
| v0.4 | 只读查看模式 | ✅ 已完成 |
| v0.5 | 碰撞检测 + 业务侧可自定义反馈 | 待开发 |

---

### v0.1 资产编辑器单页可用 ✅

**范围**：资产编辑器主体

- 资产编辑器页面骨架（左侧元器件库 + 主视口 + 右侧属性/层级树）
- 预置元器件库（柜体、断路器、接触器等占位几何）
- 拖拽/点击元器件到视口、移动/旋转/缩放、吸附、删除、撤销重做
- 保存为资产（localStorage，数据结构：name + 场景 JSON）

**验收**：能编排一个电柜并保存为资产，资产库中可看到一条记录。

---

### v0.2 资产库 + 场景编辑器 ✅

**范围**：资产管理中心 + 场景编辑器主链路

- 资产管理中心页面：**Tab 切换**「电柜资产」/「场景资产」，各自展示和管理
- 点击资产卡片 → 跳转对应编辑器（电柜 → 资产编辑器，场景 → 场景编辑器）
- 场景编辑器使用 **factoryPreset**（反射地板 + 黄色边框 + 尺寸标注）
- 右侧面板双 Tab：「基本配置」（场景名称、地板宽/深调整、通信配置占位）+「场景树」
- 从左侧资产库拖拽/点击资产到场景，创建实例
- 场景保存/加载，支持 URL 参数 `?id=xxx` 直接打开场景

**验收**：资产库 Tab 切换正常；场景编辑器有工厂地板；右侧配置面板可调整地板尺寸；保存后场景资产 Tab 中可见。

---

### v0.3 场景 ↔ 资产编辑器打通

**范围**：双编辑器间流转 + 资产编辑器加载已有资产

- **资产编辑器支持加载已有资产**：通过 `?id=xxx` 参数加载 localStorage 中的资产进行编辑
- **场景编辑器工具栏新增入口**：
  - 「新建资产」→ 跳转 `/asset-editor`，新建完保存后返回场景
  - 「编辑选中资产」→ 选中场景中的实例时可用，跳转 `/asset-editor?id=xxx` 编辑其源资产
- **返回场景**：资产编辑器保存后可导航回场景编辑器
- **实例刷新**（可选增强）：编辑资产后，场景中对应实例的几何/材质可刷新

**验收**：
1. 资产库点击已有电柜资产 → 资产编辑器加载该资产内容，可修改并覆盖保存
2. 场景编辑器中点击「新建资产」→ 跳转资产编辑器 → 保存 → 返回场景，新资产出现在左侧列表
3. 场景中选中一个实例 → 点击「编辑资产」→ 跳转并加载该资产 → 修改保存 → 返回场景

---

### v0.4 只读查看模式

**范围**：场景/资产只读浏览

- **场景查看器** `/scene-viewer?id=xxx`：
  - 加载场景，使用 factoryPreset 渲染
  - 隐藏所有编辑工具（工具栏精简为仅查看相关）
  - 仅保留相机旋转/缩放/平移导航
  - 点击对象可查看基本信息（名称、位置等），但不可编辑
- **资产查看器** `/asset-viewer?id=xxx`：
  - 加载资产并渲染，仅相机导航
  - 可查看元器件信息但不可编辑
- **入口集成**：
  - 资产库卡片增加「查看」按钮（与「编辑」并列）
  - 场景资产 Tab 卡片增加「查看」按钮

**验收**：
1. 资产库中点击查看按钮 → 以只读模式浏览资产/场景
2. 查看模式下无法修改任何对象，仅可旋转/缩放/平移相机
3. 点击对象可查看基本信息面板

---

### v0.5 碰撞检测

**范围**：内核提供碰撞检测能力，业务侧可自定义反馈

- **内核侧**（`packages/engine` 或 `packages/extensions`）：
  - 提供碰撞检测 API：如 `checkCollision(objA, objB)` 或批量检测
  - 检测两个/多个可编辑对象是否相交（包围盒或精确几何）
  - 通过事件或回调通知碰撞结果，供业务层订阅

- **业务侧**（`demo-view`）：
  - 订阅碰撞检测结果，自定义反馈形式
  - 示例：发生碰撞时对涉及对象做描边高亮、Toast 提示等
  - 业务层决定何时检测（如变换结束、拖拽放置时）、以何种方式呈现

**验收**：
1. 内核提供可调用的碰撞检测 API，demo-view 能接入
2. 场景编辑器中移动/放置资产导致相交时，业务侧能感知
3. 业务侧可实现自定义反馈（如描边高亮碰撞对象）

## 5. 需要改动的内容（分层）

### 5.1 内核侧

- `HistoryManager`：补全 transform 的 undo/redo（持续改进）
- 碰撞检测：`packages/engine` 或 `packages/extensions` 提供碰撞检测 API，支持业务侧订阅并自定义反馈（v0.5）

### 5.2 应用侧（demo-view）

- 路由：`/asset-library`、`/asset-editor`、`/scene-editor`、`/scene-viewer`、`/asset-viewer`
- 资产库与资产/场景数据持久化（本地优先）
- 资产编辑器、场景编辑器、查看模式的页面与状态管理

## 6. 验收口径（MVP 完整）

- 四大能力：**创建**（编排电柜入库）、**维护**（编辑/重命名/检索）、**场景搭建**（拖拽排布、保存加载）、**查看**（只读浏览）。
- 场景编辑器可进入资产编辑器（新建/编辑），编辑结果可回写。
- 性能：10–20 个柜体实例可流畅操作。
- 暂不纳入：实时 PLC、AR/VR、权限、云同步。
